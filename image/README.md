# 我的家庭云 Logo 设计说明

## Logo 设计理念

新Logo采用现代简约风格，融合了"家庭"与"云存储"的概念，使用莫兰迪色系，与页面整体配色保持一致。

## 配色方案

### 页面莫兰迪色系
- **豆沙绿** (#9BB0A0)：代表温馨、自然、安全感
- **雾霾蓝** (#8BA3A7)：代表科技、智慧、存储
- **哑金** (#B7A287)：代表品质、珍贵、价值
- **深灰蓝** (#2C3E4F)：代表稳重、专业、可靠

### Logo 配色
- 主色调：豆沙绿到雾霾蓝的渐变
- 点缀色：哑金色（房子图标）
- 文字色：深灰蓝（清晰易读）

## 设计元素

1. **云朵形状**：柔和的圆润设计，象征云存储服务
2. **房子图标**：简化的几何形状，象征家庭
3. **色彩搭配**：低饱和度的莫兰迪色，营造温馨、专业的氛围

- ✅ 符合莫兰迪色系
