## 莫兰迪色系特点

### 什么是莫兰迪色系？
莫兰迪色系是以意大利画家乔治·莫兰迪（Giorgio Morandi）名字命名的色系，特点是：
- **低饱和度**：颜色柔和，不刺眼
- **灰度调和**：加入灰色，降低纯度
- **温和优雅**：给人宁静、舒适的感觉
- **高级质感**：具有文艺、复古的气息

### 莫兰迪色系的优势
1. **视觉舒适**：长时间观看不会疲劳
2. **搭配和谐**：不同颜色之间自然融合
3. **高级感强**：提升品牌形象和品质
4. **易于搭配**：与各种背景色都能很好地配合
